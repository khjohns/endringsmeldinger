# Kilde til arkitekturforslaget

Dato: 2026-10-07. Kodegrunnlag for vurderingen:
`68ca0ea5b593808c4513dc84ab908baf12739cdb`, med PR #266 på `4c8860a` som forrige ledd.

[Opprinnelig forslag](opprinnelig-forslag.md) er en uendret kopi av teksten
oppdragsgiver limte inn i samtalen 07.10. Det er historisk kildegrunnlag,
ikke vedtatt målarkitektur eller en oppdatert beskrivelse av beslutningsstatus.

**Merknad 2026-10-07:** vurderingen og justeringene er flettet inn i
[det reviderte forslaget](../../forslag-maalarkitektur-og-beslutningsproeve-2026-10-07.md).
Der er blant annet B-13-presiseringen, avgrensningen av journalens autoritet,
serverkontrollene og kostnaden ved et databasebytte rettet mot kartleggingen.
Originalen beholdes for å vise hvilke antakelser vurderingen tok utgangspunkt i.

## Verifikasjon og grenser

Kopien er kontrollert byte for byte mot vedlegget fra samtalen med `cmp`.
Påstandene i originalen er ikke dermed bekreftet; belegg og grenser står i
det reviderte forslaget. Dette vedlegget innfører ingen funn eller vedtak.
