# Historisk underlag

Daterte auditer, reviewer, oppdrag, gjennomføringer, handoffer og
konsolideringer fra arbeidet før TS-stien. De bevarer hva som ble undersøkt og
begrunnet den datoen. Status, alvorlighet og kjøringer i dem gjelder den
undersøkte versjonen, ikke dagens kode.

Gjeldende status står i [hovedplanen](../plans/2026-09-16-godkjenning-og-varig-levering.md),
[arkivet](../plans/arkiv.md) og [vedtaksfila](../plans/vedtak.md).
[Dokumentasjonsindeksen](../README.md#historisk-underlag) ordner dokumentene etter
runde og sier hvilke historiske dokumenter som ligger igjen i `docs/`.
